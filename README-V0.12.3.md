# LevelUp10 V0.12.3 — Maths Number Rebuild

Built from the confirmed V0.12.2 curriculum-map baseline.

## Maths changes
- Rebuilt the Pearson Edexcel 1MA1 **Number** strand as a structured bank.
- 216 Number questions across 9 skills.
- Questions carry `strand`, `skill`, `grade`, `tier`, and `pattern` metadata.
- Foundation content is grades 2–5; surd extension content is Higher only.
- Legacy repetitive Number/Division questions were replaced rather than added to.
- `categoryFor()` now respects explicit Maths `strand` metadata, so skills can be named in `topic` while the curriculum screen still groups them under Number.
- Existing anti-repeat logic remains active.

## Preserved
Cloud identity/sync, LevelUp10 ID, Dragon Encounter, mission resume, profiles, shop, timetable, Higher readiness, and all non-Number subject content.
