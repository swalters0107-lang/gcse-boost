# LevelUp10 / GCSE Boost V0.12.2

Maths curriculum architecture update.

- Replaces legacy Maths category grouping with the six Pearson Edexcel GCSE Mathematics (1MA1) content strands.
- Adds a fine-grained skill map beneath every strand.
- Maps the existing Maths bank into the new strands without deleting or rewriting learner progress.
- Shows current question coverage per strand.
- Probability and Statistics are intentionally shown as content gaps rather than pretending current questions cover them.
- No changes to cloud identity, mission resume, Dragon encounter, coins, profiles or Supabase schema.

Next content phase: rebuild/expand Maths questions against this map and attach explicit `strand` and `skill` metadata to each new question.
