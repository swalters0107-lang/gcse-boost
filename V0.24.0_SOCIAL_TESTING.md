# V0.24.0 Social Foundations — Test Order

1. Run `supabase_v02400_social_foundations.sql` once in the existing Supabase project.
2. Deploy the full V0.24.0 application.
3. Sign in as a linked parent/carer and open the Parent Dashboard.
4. Enable Friends for the first student; optionally allow the weekly leaderboard.
5. Sign in as that student, open Profile → Rewards → Friends and confirm it opens.
6. Create a friend code.
7. Sign in as a second parent-linked student with Friends enabled and redeem the code.
8. Return to the first student and accept the request.
9. Confirm both students appear in Friends.
10. Allow the leaderboard for both students in their parent dashboards, then opt in from each student account.
11. Complete questions on both accounts and confirm weekly activity points appear.
12. Test Remove, Block and Unblock. A blocked student must disappear from Friends and the leaderboard.

Expected safety behaviour:

- Social features are locked until a linked parent/carer enables them.
- Codes expire after 24 hours and can be redeemed once.
- Emails and account UUIDs are never displayed.
- Class membership does not automatically create friendships.
- The leaderboard contains only the student and opted-in friends.
- Head-to-Head Battles remain locked.
