# GCSE Boost V0.11B.3 — Mission Resume + Algebra Upgrade

- Active missions persist locally and resume after the app is backgrounded/reloaded.
- Resumes the exact question; answered questions restore feedback and NEXT state without awarding points twice.
- Completing or deliberately leaving a mission clears the saved mission.
- Added varied algebra where x is part of the calculation, including equations, brackets, x on both sides and substitution.
- Numeric algebra accepts both `13` and `x = 13`.
- Cloud progress system from V0.11B.2.1 retained.
