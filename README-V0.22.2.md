# LevelUp10 V0.22.2 — Strict Curriculum Area Missions

Fixes category leakage in curriculum missions.

- Selecting Maths → Number now keeps all mission questions inside Number.
- The same hard boundary applies to selected curriculum areas in every subject.
- If recent-question protection exhausts unseen questions, fallback stays inside the selected area instead of widening to the whole subject.
- “All current topics” remains the mixed-area option.
- Retains V0.22.1 mastery-state rules and existing learner progress.
