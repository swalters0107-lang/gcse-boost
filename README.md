# GCSE Boost V0.11A.11 — Categories, Coverage & Estimated Grade

- Subject → Category → mission flow for all 11 subjects.
- Every subject has an All topics option.
- All topics deliberately seeds under-served categories before Smart Variety fills the mission.
- Focused category practice stays inside the chosen category.
- Profile now shows a GCSE Boost Estimated Current Grade for each subject.
- Estimates use recent accuracy plus question difficulty, require evidence, and respect the Foundation Grade 5 cap in Maths/Science.
- Sport Science and Catering use vocational-style Pass/Merit/Distinction estimates.
- Estimates are explicitly labelled as GCSE Boost estimates, not official school predicted grades.
- V0.11A.10 division content and all existing profiles, answer lock, MCQ and Smart Variety fixes remain.
