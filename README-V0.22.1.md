# LevelUp10 V0.22.1 — Mastery State Fix

Patch for the Universal Mastery Engine.

- A skill remains **New** until there is enough evidence to classify it.
- A single attempt no longer produces **Developing · 0%** or **Developing · 100%**.
- Zero-correct evidence remains **New** rather than being labelled Developing.
- Percentage is hidden while a skill is still New.
- Secure and Mastered thresholds are unchanged.
- Existing progress/history is preserved.
