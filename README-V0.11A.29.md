# GCSE Boost V0.11A.29 — Mission & Answer Engine Repair

Patch for the existing V0.11A.28 GitHub build.

## Fixes
- Category/course overlay closes before a mission starts.
- Prevents RE/category options appearing below an active question.
- All MCQ answers across every subject are shuffled with Fisher–Yates.
- The correct-answer index moves with the answer, so marking remains accurate.
- Fixes the RE bank's visible 'correct answer is always option 1' pattern.
- Keeps the V0.11A.28 organised Profile, School Week, Today's Mission, Shop, themes, coins and achievements.
