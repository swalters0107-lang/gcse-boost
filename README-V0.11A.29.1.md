# GCSE Boost V0.11A.29.1 — Always Available Home

Small patch on top of V0.11A.29.

Fix:
- HOME remains active during normal missions, Recovery Rounds, Boss Battles and Higher Readiness.
- Leaving an unfinished session returns to Home without awarding mission-completion XP or coins.
- Does not change the V0.11A.29 MCQ answer randomisation or subject/category repair.

## Upload
Upload `fix-v011a29-1.js` to the GitHub repository root.

Then replace `index.html` with the included version so the patch loads.
