# LevelUp10 V0.23.0 — Accounts & Test Groups

## Goal
Move LevelUp10 from a single-device learner app to a safe multi-user test platform without changing the adaptive learning engine.

## Roles
- learner: owns GCSE progress and can be linked to adults/classes.
- parent: can later link to one or more learners and view read-only progress.
- teacher: can later create classes, issue join codes and view read-only class progress.

## Identity model
`auth.users` is authentication only. `profiles` stores app role/display name. Existing `levelup10_identities` remains the public LevelUp10 identity. `student_data` remains the canonical learner progress row.

## Relationship model (introduced by migration)
- `guardian_learner_links`: parent <-> learner, unique pair, status pending/active/revoked.
- `teacher_classes`: class owned by one teacher, with a short join code.
- `class_memberships`: learner <-> class, unique pair, status active/left.

A learner has one progress record regardless of how many parents or teachers can view it.

## V0.23.0 scope
1. Learner, Parent and Teacher role choice during account creation.
2. Existing learner cloud sync remains unchanged.
3. Adult accounts do not create or load learner progress rows.
4. Database relationship foundation and RLS are supplied in `supabase_v0230_accounts.sql`.
5. Existing V0.22.9 learner accounts and local progress remain compatible.
